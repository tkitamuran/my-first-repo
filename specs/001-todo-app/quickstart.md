# クイックスタート: シンプル ToDo アプリ

**対象**: 実装・レビュー・受入確認を行う開発者

## 前提

- Node.js 24系
- npm 11系
- localStorage と `<dialog>` を利用できる最新安定版ブラウザー

## セットアップ

```powershell
npm install
```

実装時に追加するテスト用依存はdevDependenciesへ保存し、package-lock.jsonを更新する。

## 開発サーバー

```powershell
npm run dev
```

表示されたローカルURLをブラウザーで開く。

## 自動検証

```powershell
npm run test:run
npm run build
```

開発中にテストを監視実行する場合:

```powershell
npm test
```

## 主要な受入確認

1. 空の一覧に「タスクがありません」と登録方法が日本語で表示される。
2. 「牛乳を買う」を登録すると、未完了タスクとして一覧末尾に表示される。
3. 空白だけ、または201文字の入力は登録されず、入力欄付近に日本語エラーが表示される。
4. 同名タスクを2件登録でき、それぞれを独立して操作できる。
5. チェックボックスで完了・未完了を切り替え、同じ一覧内で文字情報として状態を確認できる。
6. 削除ボタンで対象名を含む確認ダイアログが開き、キャンセルではタスクが残る。
7. 削除を承認すると対象だけが消え、元の操作位置へフォーカスが戻る。
8. 登録後にページを再読み込みし、タスク内容と順序が復元される。
9. 完了・完了解除後に再読み込みし、最後に保存した完了状態が復元される。
10. 削除後に再読み込みし、削除対象が復元されないことを確認する。
11. localStorageの読込または各変更操作の保存を失敗させ、入力値、既存一覧、直前の保存値を
    失わず日本語エラーが出ることを確認する。
12. キーボードだけで登録、完了切替、削除確認、キャンセルを実行する。

## localStorageの確認

開発者ツールのストレージ表示で `todo-app.tasks.v1` を確認する。保存値は次の形とする。

```json
{
  "version": 1,
  "tasks": [
    {
      "id": "一意な文字列",
      "title": "牛乳を買う",
      "completed": false
    }
  ]
}
```
